# Skills

48 skills, grouped by the job they do. Ask for any of them in plain words. You never need to remember a name.

"Original" skills were written for this kit. "Rewritten" skills started from an idea in an open-source pack and were given a new method here. "Adapted" skills keep much of their open-source text, corrected and edited to work with free tools only. See [CREDITS](../CREDITS.md).
