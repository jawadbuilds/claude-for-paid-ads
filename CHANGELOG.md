# Changelog

## 0.1.0

First release.

- 48 skills for Google Ads, Meta Ads, SEO and AI search, each with a written method, including a check that removes AI-sounding and unclear copy
- 8 agents: setup guide, Google Ads manager, Meta Ads manager, creative strategist, competitor researcher, tracking checker, weekly reporter and SEO advisor
- The beginner guide, three connection guides and the safety page
- Copies of `claude-ads` v2.1.0, `claude-seo` v2.6.2 and `claude-blog` v2.3.2 as optional plugins
- `scripts/check.py`, which keeps the kit well-formed and free-only
- A page on how the kit was audited and tested, a code of conduct and a pull request template
