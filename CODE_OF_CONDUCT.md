# Code of conduct

This project is for people learning to run ads well. Many of them are new. Treat everyone here the way you would want a patient colleague to treat you.

## What we expect

- Be kind and assume good intent. A beginner's question is welcome.
- Disagree about the work, not the person.
- Give credit. If an idea or a fix came from someone else, say so.
- Keep private things private. Do not post anyone's account numbers, client names or personal details, including your own clients'.

## What is not accepted

- Insults, harassment or discrimination of any kind.
- Promotion of paid products, affiliate links or services in issues and pull requests.
- Posting someone else's private data.

## If something goes wrong

Report it privately through the "Report a vulnerability" button on the repository's Security tab, or open an issue if it is not sensitive. The maintainer reads every report and may remove comments, close threads or block accounts that break these rules.

This is a one-maintainer project, so replies are best effort.
